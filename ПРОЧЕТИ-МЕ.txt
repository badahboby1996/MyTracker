ТОВА Е ГОТОВИЯТ PWA АПП ЗА ШИРИН

Няма npm, няма инсталация и няма assets папка.

КАКВО ТОЧНО ДА НАПРАВИШ В GITHUB:

1. Разархивирай ZIP файла на компютъра.
2. Влез в repository-то, което ще използваш за приложението.
3. Изтрий старите файлове от неуспешната версия.
4. Натисни Add file > Upload files.
5. Качи всички файлове от разархивираната папка. Файлът index.html трябва да се вижда директно на началния екран на repository-то, а не вътре в допълнителна папка.
6. Натисни Commit changes.
7. Отвори Settings > Pages.
8. Под Build and deployment избери Deploy from a branch.
9. Избери branch: main и folder: /(root), след това Save.
10. Изчакай 1–3 минути и отвори адреса, който GitHub показва в Pages. Не отваряй index.html от списъка с файлове в GitHub — това не е адресът на приложението.

НА IPHONE:

1. Отвори готовия GitHub Pages адрес в Safari.
2. Натисни Share.
3. Избери Add to Home Screen / Добавяне към Начален екран.
4. Натисни Add / Добави.

Приложението пази отметките за пазар и прогреса локално на телефона.
