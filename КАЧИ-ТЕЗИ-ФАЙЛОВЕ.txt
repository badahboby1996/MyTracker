ХРАНИТЕЛЕН ПЛАН – ШИРИН

Това е готовата версия за директно качване. Не изпълнявай npm install и не разархивирай node_modules – такива файлове няма в този пакет.

ЗА GITHUB PAGES:
1. Разархивирай ZIP файла.
2. Качи ВСИЧКИ файлове и папката assets в основната папка на repository-то.
3. В GitHub отвори Settings > Pages.
4. Избери Deploy from a branch, branch main и папка /(root).
5. Натисни Save и изчакай GitHub да даде адреса.

Важно: не променяй имената и не изваждай файловете от папка assets. Приложението пази пазаруването и прогреса локално на телефона.
